# SKILL: DIRECT RESPONSE — NÍVEL SÊNIOR

## O QUE É DIRECT RESPONSE

Copy de resposta direta tem um único objetivo: **fazer o leitor agir agora**.
Diferente de branding, aqui cada palavra é medida pelo resultado que gera.

Princípio central: **toda copy ruim é vaga. Toda copy boa é específica e urgente.**

## OS 5 ELEMENTOS INEGOCIÁVEIS

### 1. HEADLINE
A headline faz 80% do trabalho. Se ela não parar, nada mais importa.

**Fórmulas que funcionam sempre:**
- `[Resultado específico] em [tempo específico] sem [maior objeção]`
- `Como [pessoa comum] conseguiu [resultado desejado] mesmo [adversidade]`
- `O segredo de [fonte de autoridade] para [resultado desejado]`
- `[Número] maneiras de [resultado] que [grupo] não quer que você saiba`
- `Aviso: [consequência grave] se você continuar [comportamento do avatar]`

**Regras da headline:**
- Sempre prometa um benefício ou desperte curiosidade irresistível
- Seja específica: números, prazos, nomes reais
- Fale com UMA pessoa, não com multidões
- Teste sempre pelo menos 3 versões

---

### 2. LEAD (abertura)
Os primeiros parágrafos determinam se a copy será lida.

**Os 6 tipos de lead (Eugene Schwartz):**
1. **Oferta direta** — para avatar mais consciente, mostra a oferta na largada
2. **Promessa** — benefício principal explícito desde o início
3. **Problema** — começa pela dor que o avatar sente agora
4. **Historia** — narrativa que puxa o avatar para dentro
5. **Segredo** — algo que o avatar não sabe e precisa saber
6. **Desafio** — provoca o avatar a questionar o que acredita

**Regra:** quanto menos consciente o avatar, mais indireta deve ser a lead.

---

### 3. MECANISMO ÚNICO
É o "porquê" exclusivo do seu produto. O que explica o resultado de forma nova.

**Estrutura:**
- Mecanismo Problema: por que o avatar ainda não resolveu
- Mecanismo Solução: como especificamente o produto resolve

**Exemplos:**
- ❌ fraco: "emagreça com nossa dieta"
- ✅ forte: "você não emagrece porque suas bactérias intestinais estão bloqueando o hormônio que queima gordura — e a ciência descobriu como reativar esse processo em 21 dias"

O mecanismo deve ser: **novo, lógico, crível e exclusivo**.

---

### 4. PROVA
Sem prova, copy é ficção. O cético compra quando vê evidência.

**Hierarquia de prova (do mais ao menos poderoso):**
1. Demonstração ao vivo (o produto funcionando)
2. Resultados com números reais e nomes reais
3. Depoimentos em vídeo com antes e depois
4. Depoimentos escritos com especificidade
5. Endosso de autoridade reconhecida
6. Lógica e explicação científica
7. Garantia (prova pelo risco invertido)

---

### 5. OFERTA IRRESISTÍVEL
Ninguém compra o produto. Compram o que o produto vai fazer por eles.

**Estrutura da oferta:**
1. Produto principal + o que ele entrega
2. Bônus (cada um com valor percebido declarado)
3. Preço âncora (o quanto valeria se fosse justo)
4. Preço real (com justificativa do desconto)
5. Garantia (inverte o risco)
6. Urgência/escassez (real, nunca falsa)
7. CTA único e claro

## EMOÇÃO DOMINANTE (Clayton Makepeace)

Toda copy deve identificar e amplificar a **emoção dominante** do avatar.

As 7 emoções que mais vendem:
1. **Medo** (de perder, de errar, de ficar para trás)
2. **Ganância** (de ganhar mais, ter mais)
3. **Culpa** (não estar fazendo o suficiente)
4. **Raiva** (de quem os prejudica, do sistema)
5. **Exclusividade** (fazer parte de algo especial)
6. **Salvação** (ser resgatado de uma situação ruim)
7. **Amor/orgulho** (ser admirado, proteger quem ama)

**Como usar:** identifique qual é a emoção dominante do avatar e construa a copy inteira em torno dela.

## NÍVEIS DE CONSCIÊNCIA (Eugene Schwartz)

| Nível | Estado do avatar | Como abordar |
|-------|-----------------|--------------|
| 1 - Sem consciência | Não sabe que tem o problema | História, curiosidade, padrão interrompido |
| 2 - Consciente do problema | Sabe da dor, não da solução | Agite a dor, apresente a categoria de solução |
| 3 - Consciente da solução | Sabe que existe solução, não conhece você | Apresente seu mecanismo único |
| 4 - Consciente do produto | Conhece você, não comprou | Oferta, prova, urgência |
| 5 - Mais consciente | Conhece tudo, hesita | Melhor oferta, bônus, garantia estendida |

## FRAMEWORKS DE ESCRITA

### PAS — Problema / Agitação / Solução
Melhor para: ads, posts, e-mails
```
P: identifique o problema com precisão
A: aprofunde a dor (o que acontece se não resolver)
S: apresente a solução como alívio
```

### AIDA — Atenção / Interesse / Desejo / Ação
Melhor para: ads, landing pages, e-mails de venda
```
A: capture a atenção (headline + hook)
I: gere interesse (curiosidade, história, dado)
D: crie desejo (benefícios, prova, mecanismo)
A: provoque a ação (CTA + urgência)
```

### PASTOR (Ray Edwards)
Melhor para: sales pages longas, VSLs
```
P: Problem — o problema do avatar
A: Amplify — amplifique as consequências
S: Story/Solution — história que leva à solução
T: Transformation — a transformação que o produto entrega
O: Offer — a oferta completa
R: Response — o CTA
```

### BEFORE / AFTER / BRIDGE
Melhor para: headlines, posts, abertura de VSL
```
Before: a vida do avatar hoje (com a dor)
After: a vida do avatar com o problema resolvido
Bridge: o produto é a ponte entre os dois
```

## GATILHOS MENTAIS — COMO USAR

| Gatilho | Como aplicar em copy |
|---------|---------------------|
| Escassez | "Apenas 47 vagas" / "Oferta encerra sexta" — sempre real |
| Urgência | Prazo real com consequência clara se não agir |
| Autoridade | Credenciais, resultados, mídia, anos de experiência |
| Prova social | Números reais ("mais de 12.400 alunos"), depoimentos |
| Reciprocidade | Entregue valor antes de pedir a venda |
| Especificidade | "Perca 7,3kg" > "Perca peso" |
| Curiosidade | Lacuna de informação que só se fecha lendo mais |
| Identidade | "Para mulheres acima dos 40 que..." |
| Garantia | Inverta o risco completamente para o comprador |

## REGRAS DE OURO DO DIRECT RESPONSE

1. **Uma copy, uma ideia, uma ação.** Nunca divida o foco.
2. **Escreva para uma pessoa.** Nunca para um grupo.
3. **Pesquisa antes de escrever.** 80% pesquisa, 20% escrita.
4. **O avatar compra com emoção, justifica com lógica.** Dê os dois.
5. **Especificidade é credibilidade.** Quanto mais específico, mais crível.
6. **Nunca assuma que o leitor vai rolar.** Cada parágrafo deve puxar para o próximo.
7. **Teste sempre.** Nenhuma versão é a versão final.
8. **A oferta importa mais que a copy.** Uma oferta ruim, nenhuma copy salva.
9. **Headlines são 80% do resultado.** Invista mais tempo nelas.
10. **Clareza > criatividade.** Copy que confunde não converte.
