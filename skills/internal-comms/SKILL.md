# Internal Communications Skill

Guidance for writing internal company communications across multiple formats.

## Supported Communication Types

The skill covers seven primary communication categories:
- 3P updates (Progress, Plans, Problems)
- Company newsletters
- FAQ responses
- Status reports
- Leadership updates
- Project updates
- Incident reports

## Implementation Process

To use this skill, first identify which type of communication is needed, then locate and follow the corresponding guideline file from the `examples/` directory. The available templates address specific formats: 3P updates, company-wide newsletters, FAQ responses, and general communications that don't fit the other categories.

## Key Details

The resource is organized around matching communication requests to their appropriate template, with instructions emphasizing that "if the communication type doesn't match any existing guideline, ask for clarification or more context about the desired format."

The skill is designed to help writers produce communications aligned with company preferences and established formatting standards.
