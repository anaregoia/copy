# Canvas Design Skill

A two-step process for creating visual art and design: first creating a design philosophy (aesthetic manifesto in .md format), then expressing it visually through .pdf or .png outputs.

## Core Philosophy

The approach emphasizes "minimal text as visual accent" and "painstaking attention" to detail, treating design as sophisticated art rather than decoration.

## Key Principle

The work should appear "meticulously crafted" and "the product of countless hours" by someone with "master-level execution" — visual communication takes priority over text, which remains sparse and integrated.

## Process

1. Create a design philosophy document defining the aesthetic direction
2. Express that philosophy visually through canvas-based outputs
3. Use fonts from the `canvas-fonts/` directory for consistent typography
