# Theme Factory

Toolkit for styling artifacts with a theme. These artifacts can be slides, docs, reportings, HTML landing pages, etc.

## Overview

This skill offers 10 professionally curated font and color themes designed to apply consistent styling to various presentation formats.

## How to Use

1. Display the `theme-showcase.pdf` file for visual review
2. Request user's theme preference
3. Obtain explicit confirmation of selection
4. Apply chosen theme's colors and fonts throughout the artifact

## Available Themes (10 options)

1. Ocean Depths
2. Sunset Boulevard
3. Forest Canopy
4. Modern Minimalist
5. Golden Hour
6. Arctic Frost
7. Desert Rose
8. Tech Innovation
9. Botanical Garden
10. Midnight Galaxy

## Theme Implementation

Each theme includes hex color codes, header/body font pairings, and specifications located in the `themes/` directory for consistent application across all slides.

## Custom Theme Option

When existing themes don't suit your needs, generate a custom theme based on provided preferences, present it for approval, then apply it using the standard process.
