# Doc Co-Authoring Workflow

A comprehensive guide for assisting users through collaborative document creation.

## Overview

This skill helps users write structured documents like proposals, specs, and decision docs through three stages: context gathering, refinement, and reader testing.

## Key Stages

**Stage 1: Context Gathering**
The process begins by collecting meta-context about the document type, audience, and desired impact. Users can "dump" information however works best, and Claude asks clarifying questions to ensure understanding.

**Stage 2: Refinement & Structure**
Documents are built section-by-section through brainstorming options, curating selections, and iterative refinement using targeted edits rather than full rewrites.

**Stage 3: Reader Testing**
The completed draft is tested with fresh Claude instances (without prior context) to identify blind spots and ambiguities before actual readers encounter it.

## Core Principle

The workflow emphasizes that "the goal is a document that actually works for readers" by catching assumptions and unclear passages through systematic testing before publication.

The guidance prioritizes user agency, allowing flexibility to skip stages or work freeform if preferred, while maintaining procedural clarity throughout the process.
