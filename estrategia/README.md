## O veredito em 5 linhas

1. **Seu maior ativo não é o serviço — é a prova.** Você tem cases com números que 95% das agências não têm (R$2k → R$47k; posição 20+ → nº 1 no bairro inteiro). Isso está enterrado em PDFs. Precisa virar página de cases pública.
2. **Sua história é o posicionamento:** dentista por 20 anos que virou estrategista de Google. "De dentista para dentista" ninguém copia. Pare de se apresentar como copywriter genérica ou agência de ads.
3. **Existem 3 marcas concorrendo entre si** nos seus materiais (AdsDigital, AR Consultoria, Ana Rego). Unifique tudo em **Ana Rego**.
4. **O preço de R$600 sabota o ticket alto.** O mesmo trabalho que gerou R$47k para um cliente não pode ancorar em R$600. A nova esteira vai de diagnóstico pago a plano premium recorrente.
5. **Google Ads sai, e o que entra é mais valioso:** SEO local + GMN + site/blog otimizado para IA é exatamente onde o mercado está indo (buscas respondidas por IA). Você chegou cedo — isso é a sua tese de autoridade.
