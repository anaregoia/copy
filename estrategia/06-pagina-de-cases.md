# 06 — A aba de Cases: estrutura, template e ordem de produção

## Arquitetura

```
anarego.com.br/cases            ← página-hub (vitrine + filtros)
anarego.com.br/cases/faces-odontologia   ← 1 página por case (SEO individual)
anarego.com.br/cases/nitz-odontologia
...
```

Página individual por case é o que ranqueia ("marketing para dentista case", "SEO local odontologia resultado") e é o link que você manda no WhatsApp durante a venda.

## A página-hub

1. **Headline:** *"Resultados medidos, não prometidos."*
2. **Sub:** *"Todo cliente entra com um scan de posição e acompanha a evolução no mapa. Estes são alguns antes e depois — com prazo, investimento e faturamento."*
3. **Barra de totais** (some conforme os cases publicados): `+ de X clínicas atendidas` · `casos com SoLV 0→100` · `R$ XXk em tratamentos fechados via Google documentados`
4. **Cards** (grid 3 colunas): logo do cliente, especialidade + cidade, **1 métrica de impacto** ("20+ → 1º lugar em 110 dias" / "R$4k investidos → R$39k faturados"), botão "ver caso completo".
5. **Filtro** por especialidade (Implantes/Lentes · Odontopediatria · Medicina · Estética).
6. **Depoimentos em rodapé** + CTA único: "Quero um diagnóstico como esse para a minha clínica".

## Template do case individual (7 blocos — copie para todos)

1. **Resumo em números (hero):** 3 KPIs grandes.
   *Ex. Faces: "Posição média: 20+ → 1,2" · "Cobertura em 1º lugar (SoLV): 0% → 100%" · "110 dias".*
2. **O cliente:** 2 linhas (especialidade, cidade, momento). *"Clínica especializada em lentes de contato dental em Águas Claras/DF. Excelência técnica, invisibilidade digital."*
3. **O desafio (ANTES):** print do geo-grid vermelho + tradução leiga: *"Em junho, quem buscasse 'lentes de contato dental' em qualquer ponto do bairro não encontrava a clínica entre os 20 primeiros."*
4. **O que foi feito:** 4–6 bullets mapeados nos pontos do Método Bússola (N/L/S/O). Sem segredo técnico demais — mostre método, não a receita inteira.
5. **O resultado (DEPOIS):** grid verde + funil (investimento → leads → agendamentos → faturamento) + prints de WhatsApp autorizados (nomes de pacientes borrados) + **prazo explícito**.
6. **Depoimento** do dono da clínica (texto ou vídeo de 40s).
7. **CTA:** "Sua clínica pode ser o próximo case → Diagnóstico Bússola".

## Checklist antes de publicar cada case (obrigatório)

- [ ] **Autorização por escrito** do cliente (WhatsApp print vale, mas ideal é 3 linhas assinadas): uso de nome, logo, números e prints;
- [ ] Nome/foto de **pacientes** sempre borrados (LGPD + ética CFO/CFM);
- [ ] Sem promessa implícita de posição ("garantimos 1º lugar" ✗) — sempre "resultado obtido neste caso";
- [ ] Prazo e investimento explícitos (credibilidade);
- [ ] Métrica traduzida para leigo ao lado de cada sigla;
- [ ] Schema `Article` + breadcrumb; depoimento com markup `Review` quando houver.

## Processo para gerar cases novos (vira rotina de onboarding)

1. Dia 0: scan geo-grid + screenshot do perfil + score → pasta do cliente;
2. Mensal: scan + coleta de prints de fechamento no WhatsApp (pedir na hora: "posso guardar esse print para o seu case?");
3. Dia 90: pedir depoimento (roteiro: *"como era antes / o que mudou / para quem você indica"*) + avaliação no SEU perfil do Google;
4. Publicar case → post GMN + Instagram + LinkedIn no mesmo dia.
